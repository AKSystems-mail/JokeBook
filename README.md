## iOS Deployment

**Prerequisites:**
*   Flutter SDK installed.
*   Xcode installed.
*   An active Apple Developer Program account.

**Initial One-Time Setup / Configuration:**
1.  Clone the repository: `git clone <repository_url>`
2.  Navigate to the project directory: `cd YourAppName` (or the current project name, which is `YourAppName` as per `pubspec.yaml`)
3.  Get Flutter dependencies: `flutter pub get`
4.  **Firebase Configuration:** Download your `GoogleService-Info.plist` file from the Firebase console and place it in the `ios/Runner/` directory. Open `ios/Runner.xcworkspace` in Xcode and add the `GoogleService-Info.plist` file to the Runner target (drag it into the Runner folder in the Project Navigator, ensure "Copy items if needed" is checked and it's added to the Runner target).
5.  **Project Identifiers:**
    *   Update `pubspec.yaml`: Change `name` (currently `YourAppName`) and `description` (currently `Your app description.`) to your actual app details if they are still placeholders.
    *   In Xcode (open `ios/Runner.xcworkspace`):
        *   Select the `Runner` project, then the `Runner` target.
        *   Go to the "General" tab. Update "Display Name" (currently `YourAppName`) and "Bundle Identifier" (currently `com.example.yourappname`) to your actual app details.
        *   Go to the "Signing & Capabilities" tab and select your Development Team (currently placeholder `YOUR_TEAM_ID` in `project.pbxproj`). This is required for signing.
6.  **App Icons:** Replace the placeholder icons in `ios/Runner/Assets.xcassets/AppIcon.appiconset/` with your own app icons.

**Building for Release:**
There are two main ways to build the app for release:

*   **Using Flutter CLI (Recommended for most cases):**
    ```bash
    flutter build ipa --release
    ```
    This command will produce an `.ipa` file (usually in `build/ios/ipa/`) and also an archive (`.xcarchive`) that you can find in the Xcode Organizer if needed.

*   **Using Xcode:**
    1.  Ensure all previous setup steps are complete.
    2.  Open the Xcode workspace: `open ios/Runner.xcworkspace`
    3.  In Xcode, select "Product" > "Scheme" > "Runner".
    4.  Select "Product" > "Destination" > "Any iOS Device (arm64)".
    5.  Select "Product" > "Archive".
    6.  Once the archive is built, the Xcode Organizer will open. You can distribute the app from there.

**Uploading to App Store Connect:**
1.  From the Xcode Organizer (after archiving), you can validate and distribute the app directly to App Store Connect.
2.  Alternatively, you can use Apple's Transporter app to upload the `.ipa` file generated by the `flutter build ipa` command.
3.  Log in to [App Store Connect](https://appstoreconnect.apple.com/) to prepare your app submission, including metadata, screenshots, pricing, and availability.

**Important Notes:**
*   Always ensure your project is committed to version control before starting a build.
*   Increment the build number in `pubspec.yaml` (e.g., `1.0.0+2`, current is `1.0.0+1`) and `ios/Runner/Info.plist` (`CFBundleVersion`, current is `1`) for each new build you submit to App Store Connect for the same app version.
