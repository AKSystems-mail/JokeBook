# Ostensibly An Upgrade: Release Notes for People Who Read These Things

We've once again tinkered with the audio recording, because clearly, it wasn't complicated enough. Now you can hover over it and read a description that, in all likelihood, will state the obvious. A game-changer, we know. We're already planning the victory parade.
